## 🚀 Обновление версии 0.59.2
_Дата релиза: 18 августа 2026_

### ✨ Новые возможности

- **Добавлен офлайн-режим для ассетов**
  Если вам достаточно использовать телефон как портфолио и экономить мобильный трафик, ассет можно держать в офлайн-режиме и в любой момент включить синхронизацию.

- **Добавлена поддержка Monero на Trezor**

### ⚙️ Улучшения

- **Оптимизирована работа с адресами**
  Теперь для получения адреса не требуется полная синхронизация.

- **Улучшено распознавание адресов из QR-кодов**
  Доработан механизм определения адресов, что помогает корректно читать проблемные QR-коды, созданные в Bitrefill.

## 🚀 Обновление версии 0.59.1
_Дата релиза: 12 августа 2026_

### ✨ Новые возможности

- **Добавлено скрытие баланса переворотом телефона**

- **Добавлена возможность указать сумму получения при обмене**
  Теперь можно задать сумму целевого токена или монеты.

### ⚙️ Улучшения

- **Доработан режим офлайн-транзакций для ZEC, TRX и XMR**
  Теперь для передачи данных используется анимированный QR-код из нескольких кадров, что позволяет передавать больше информации.

- **Доработан механизм клонирования кошелька**
  Пользователь может выбрать, какие токены импортировать при клонировании.

- **Улучшена проверка TRX-адресов при проблемах с синхронизацией или интернет-соединением**

- **Выплаты из пула и шлюза для PirateCash, Cosanta и wDASH теперь отображаются как Token Bridge**

### 🐛 Исправления

- **Исправлено падение Monero при потере соединения во время обработки блоков**

- **Исправлена недоступность выбора провайдера на экране сложного обмена в два шага**

- **Исправлено отображение кошельков для наблюдения в менеджере кошельков**

- **Комиссия теперь скрывается вместе с балансом на экране ассета**

- **Исправлено отображение подписи переключателя Monero на экране импорта кошелька**
