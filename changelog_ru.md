## 🚀 Обновление версии 0.59.0
_Дата релиза: 28 июля 2026_

### ✨ Улучшения

- **Добавлена поддержка TRON и токенов TRC-20 для Trezor**

- **Добавлена интеграция Unstoppable DEX**

- **Название кошелька теперь скрывается вместе с балансом**

- **Добавлено корректное отображение активного Premium-кошелька в отдельном блоке**

- **Улучшено отображение ассета, если он ещё не синхронизирован**

- **Добавлена возможность создавать офлайн-транзакции**
  Если нет подключения к интернету, транзакцию можно подготовить на одном устройстве и передать на другое удобным способом для последующей отправки в сеть.

- **Добавлена возможность поиска и сортировки транзакций**

- **Модальные окна приведены к единому фону**

### 🐛 Исправления

- **Улучшен механизм подписи транзакций картами Tangem**

- **Исправлено отображение BNB при обмене через PancakeSwap**

- **Исправлена проблема с добавлением пользовательского токена на карте Tangem**

- **Виджеты теперь корректно работают в режиме энергосбережения**

- **Доработан механизм запрета создания скриншотов при восстановлении из бэкапа**

- **Удалена логика SWAP 5 для MiniApp**

- **Повышена стабильность приложения при работе с Bitcoin Kit**
