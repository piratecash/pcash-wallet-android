## 🚀 Обновление версии 0.58.0
_Дата релиза: 22 июля 2026_

### ✨ Улучшения

- **Аппаратный кошелёк Trezor теперь работает через прямое USB-подключение**
  Для подключения больше не требуется deep link в приложение Trezor.

- **Добавлен новый провайдер обмена PayCore**

- **Добавлена возможность поиска транзакций**

- **Добавлена возможность создавать офлайн-транзакции**
  Если у пользователя есть проблемы с интернетом, транзакцию можно подготовить на одном устройстве и передать на другое любым удобным способом, чтобы затем отправить её в сеть.
  Например, это можно сделать через Meshtastic.

- **Добавлены типы провайдеров при обмене**
  Теперь пользователю понятнее, как именно выполняется обмен.

- **Доработан режим отображения ассета**
  Интерфейс теперь понятнее показывает, когда ассет ещё не синхронизирован.

- **Добавлена возможность включать сортировку транзакций**

- **Модальные окна приведены к единому фону**

- **Повышена скорость холодного старта приложения**

### 🐛 Исправления

- **Доработан автоматический перезапуск ZEC Kit в случае его остановки**

- **Исправлена ошибка WalletConnect при работе с картами Tangem**

- **Оптимизирована работа Monero с хранилищем блоков транзакций**

- **Исправлен краш при возврате на экран подтверждения отправки после выгрузки приложения из памяти**
  Проблема могла возникать, если приложение было свернуто, а система успевала выгрузить его из памяти до возврата пользователя.

- **Исправлены проблемы со стабильностью и производительностью приложения**
