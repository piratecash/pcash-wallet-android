## 🚀 Version 0.59.1 Update
_Release date: August 12, 2026_

### ✨ New Features

- **Added balance hiding by flipping the phone**

- **Added the ability to set the receive amount for swaps**
  You can now specify the target token or coin amount.

### ⚙️ Improvements

- **Improved offline transactions for ZEC, TRX, and XMR**
  Data transfer now uses an animated multi-frame QR code, allowing more information to be passed between devices.

- **Improved the wallet cloning flow**
  Users can now choose which tokens to import when cloning a wallet.

- **Improved TRX address validation when the blockchain is not synced or the internet connection is unstable**

- **Pool and gateway payouts for PirateCash, Cosanta, and wDASH are now shown as Token Bridge transactions**

### 🐛 Fixes

- **Fixed a Monero crash when the connection is lost while processing blocks**

- **Fixed provider selection being unavailable on the advanced two-step swap screen**

- **Fixed the appearance of watch-only wallets in the wallet manager**

- **Network fees are now hidden together with the balance on the asset screen**

- **Fixed the Monero switch label on the wallet import screen**

## 🚀 Version 0.59.0 Update
_Release date: July 28, 2026_

### ✨ Improvements

- **Added support for TRON and TRC-20 tokens on Trezor**

- **Added Unstoppable DEX integration**

- **Wallet name is now hidden together with the balance**

- **Improved visibility of wallets with active Premium in a separate section**

- **Improved the asset screen when an asset is still syncing**

- **Added support for creating offline transactions**
  If there is no internet connection, a transaction can be prepared on one device and transferred to another device for broadcasting to the network.

- **Added transaction search and sorting**

- **Unified the background style of modal windows**

### 🐛 Fixes

- **Improved transaction signing flow with Tangem cards**

- **Fixed BNB display during PancakeSwap swaps**

- **Fixed an issue adding user-entered tokens on Tangem cards**

- **Widgets now work correctly in battery saver mode**

- **Improved screenshot blocking during backup recovery**

- **Removed SWAP 5 logic from MiniApp**

- **Improved app stability when working with Bitcoin Kit**
