## 🚀 Version 0.59.0 Update
_Release date: July 28, 2026_

### ✨ Improvements

- **Added support for TRON and TRC-20 tokens on Trezor**

- **Added Unstoppable DEX integration**

- **Wallet name is now hidden together with the balance**

- **Improved visibility of wallets with active Premium in a separate section**

- **Improved the asset screen when an asset is still syncing**

- **Added support for creating offline transactions**
  If there is no internet connection, a transaction can be prepared on one device and transferred to another device for broadcasting to the network.

- **Added transaction search and sorting**

- **Unified the background style of modal windows**

### 🐛 Fixes

- **Improved transaction signing flow with Tangem cards**

- **Fixed BNB display during PancakeSwap swaps**

- **Fixed an issue adding user-entered tokens on Tangem cards**

- **Widgets now work correctly in battery saver mode**

- **Improved screenshot blocking during backup recovery**

- **Removed SWAP 5 logic from MiniApp**

- **Improved app stability when working with Bitcoin Kit**
